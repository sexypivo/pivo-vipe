# pivo-vipe

Spigot/Bukkit-плагин для Minecraft **1.16.5**: обратный отсчёт до закрытия сервера на вайп с тайтлом у всех игроков, после чего сервер закрывается на вайп (`whitelist on`).

## Команды

| Команда | Описание |
|---|---|
| `/pivovipe start` | Запускает отсчёт (время берётся из `config.yml`, по умолчанию 120 секунд) |
| `/pivovipe reload` | Перечитывает `config.yml` без перезапуска сервера |

Право: `pivovipe.use` (по умолчанию — `op`).

## Что происходит

1. Каждую секунду всем онлайн-игрокам показывается тайтл:
   - `&6&lВайп`
   - `&fДо закрытие вайпа осталось %time%`
2. По окончании отсчёта:
   - показывается финальный тайтл;
   - сообщение рассылается в чат всем;
   - выполняется консольная команда `whitelist on` — сервер закрывается на вайп.

## Настройка (`config.yml`)

Создаётся автоматически в `plugins/pivo-vipe/config.yml` при первом запуске. Можно менять:

- `countdown-seconds` — длительность отсчёта в секундах;
- `title.main` / `title.sub` — текст тайтла во время отсчёта (`%time%` подставляется автоматически);
- `end-title.main` / `end-title.sub` — тайтл в момент закрытия;
- `broadcast-message` — сообщение в чат при вайпе;
- `messages.*` — тексты ответов команд.

После изменения файла выполни `/pivovipe reload`.

## Сборка

Требуется Maven и доступ к репозиторию SpigotMC (Spigot API не публикуется в Maven Central — собери/скачай его через [BuildTools](https://www.spigotmc.org/wiki/buildtools/) или убедись, что он есть в локальном `.m2`).

```bash
mvn clean package
```

Готовый файл: `target/pivo-vipe.jar`.

## Установка

1. Скопируй `pivo-vipe.jar` в папку `plugins` сервера.
2. Перезапусти сервер.
3. Настрой `plugins/pivo-vipe/config.yml` по вкусу и выполни `/pivovipe reload` (либо просто перезапусти сервер).

## Требования

- Minecraft **1.16.5**
- Spigot/Paper API `1.16.5-R0.1-SNAPSHOT`
- Java 8+

## Лицензия

Используй как хочешь — плагин написан под конкретную задачу (обратный отсчёт перед вайпом сервера).
